# Inventory Management System

A Spring Boot based Inventory Management System designed to manage products, stock levels, and inventory operations efficiently. The application provides RESTful APIs and a clean backend architecture for handling inventory-related functionalities.

---

## 🚀 Features

- Product Management
- Inventory Tracking
- Add / Update / Delete Products
- Stock Management
- REST API Integration
- CRUD Operations
- Database Connectivity with JPA/Hibernate
- Clean Layered Architecture
- Maven Project Configuration

---

## 🛠️ Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven
- MySQL
- REST APIs

---

## 📂 Project Structure

```text
src/main/java/
 ├── controller      # Handles HTTP Requests
 ├── service         # Business Logic Layer
 ├── repository      # Database Access Layer
 ├── model           # Entity Classes
 └── resources       # Configuration Files
```

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/inventory-management-system.git
```

### 2️⃣ Open in IntelliJ IDEA

Import as Maven Project.

### 3️⃣ Configure Database

Update your `application.properties` file:

```properties
spring.datasource.url=YOUR_DATABASE_URL
spring.datasource.username=YOUR_USERNAME
spring.datasource.password=YOUR_PASSWORD
```

### 4️⃣ Run Application

Run the Spring Boot application from IntelliJ IDEA.
